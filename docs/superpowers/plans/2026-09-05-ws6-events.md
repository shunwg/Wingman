# WS6 — Events: organiser dashboard, QR, event board

> Scoped in `2026-09-05-wingman-v4.md` § WS6. Cites: O2 O6 O8 T5 J10. Admission, marks and badges landed in WS3; chat in WS4.

## Tasks

1. **QR** — `design/patterns/QrCode.tsx` renders the invite link as inline SVG from `qrcode`'s pure `create()` (no canvas, works in both themes). One dependency, justified in the commit.
2. **Badge links** — an invite link may carry a badge: `#/join/CODE-speaker`. Joining through it grants `badgeIds: ['speaker']`. That is how an organiser makes speakers findable as speakers without a member list to edit.
3. **InviteScreen** (`#/circles/:id/invite`, organiser only) — the link, the six-character code large in mono for a slide, the QR for a lanyard, one row per badge with its own link, "Add more people" (append hashes to a list circle), Copy / Share (`navigator.share` when present), and the pricing line: free while in beta, per-event pricing for organisers.
4. **AdminScreen** (`#/circles/:id/admin`, organiser only) — bucketed members, bucketed "met through this circle" (`MeetRequest.circleId?` set at send time when both share a live circle), the announcement editor (`announcements[circleId]` in the store, shown as the General's pin), close the circle (sets `runs.to` to today). Non-organisers get the not-found state.
5. **Event board** — `Circle.venue?: { cityKey, label }`; Grid Week's venue is Singapore. `selectors/event.ts`: for each live event circle I am in with a venue, its members who chose to be seen (redacted, decorated) with context "At Grid Week · Hall B". `BoardScreen` shows an "At {event}" section above the trips; a member with no flight at all sees it. `ContextStrip` gains "At Grid Week · N days left".
6. **Pitch page** — `public/organisers.html`, same tokens as the memo, linked from the Circles pitch card as "For organisers". Deploys with the app.
7. **CircleScreen** — organiser actions: Invite people · Manage.
8. **Tests** — `QrCode.uitest.tsx` (renders an svg with modules), `badgeLink.test.ts` (code ↔ badge parse), `event.selector.test.ts` (member without a trip sees Grid Week members; finished event yields none), `AdminScreen.uitest.tsx` (non-organiser not found), `e2e/organiser.spec.ts` (the ten-minute path: create → paste list → QR visible → pin a welcome → General shows the pin).

## Exit

QR invite, short code, admin screen with bucketed counts, announcements, event-bound board. `verify`, `lint`, `e2e` green.
